# Agoryx — опис продукту

**Поточна версія: 0.1.0.**

Agoryx — локальний застосунок для спільної роботи людини з кількома AI-агентами. Claude Code і Codex працюють через власні CLI та наявні входи в акаунти. Користувач отримує спільну розмову, проєкти, стіл із поточним станом роботи та окремі інтерфейси для різних способів співпраці.

## Як починається робота

Одна дія **New conversation** відкриває поле задачі. У ньому користувач обирає режим і, за потреби, проєкт. Work додатково дозволяє визначити робочу папку та окрему Git-гілку через worktree.

У сайдбарі всі розмови видно разом. Розмови з проєктами згруповані за проєктами; іконка показує режим. Проєкт може містити і звичайні чати, і роботу з файлами, і будь-який із чотирьох протоколів.

## Режими

| Режим | Основне призначення |
| --- | --- |
| Chat | Обговорити питання або розвинути ідею без підключення робочої папки. |
| Work | Створювати й змінювати файли у визначеній папці. |
| Verification | Створити результат, незалежно перевірити його за початковими критеріями та виправити знайдене. |
| Council | Отримати незалежні позиції, взаємну оцінку й підсумок зі збереженими розбіжностями. |
| Tournament | Порівняти короткі незалежні прототипи до вибору повної реалізації. |
| Debate | Перевірити аргументи «за» і «проти» з коректним переказом позицій та незалежним суддею. |

Режими доповнюють один одного в межах розмови. Перед прихованою сесією користувач явно обирає повідомлення, завершені результати й файли, які стануть спільними вхідними даними.

## Що робить інтерфейс корисним

**Conversation** показує діалог і виконану роботу. **Table** показує актуальний стан, рішення, докази, кроки та компоненти, які агенти підготували під конкретну задачу. **Sessions** зберігає історію протоколів, звіти та рішення користувача.

Кожен протокол має свою робочу поверхню: артефакт і докази; синтез і розбіжності; порівняння прототипів; аргументи й вердикт. Це дає альтернативу читанню довгого чату.

## Реальні межі

- Дані Agoryx зберігаються локально; запити до моделей передаються відповідним провайдерам.
- Приховані фази зараз підтримуються на macOS через Seatbelt. Якщо ізоляцію не можна забезпечити, запуск забороняється.
- Desktop-білд — для Apple Silicon. Потрібен встановлений Node.js 22+.
- Згенеровані в протоколах файли доступні для перегляду та завантаження. Вони не застосовуються до проєкту автоматично.
- Згода агентів не дорівнює доведеній правильності. Звіт зберігає невідоме та відмінність між реально виконаною перевіркою і міркуванням.
